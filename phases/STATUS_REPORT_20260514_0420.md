## What Forensa does

For each agent event ingested, Forensa produces a tamper-evident, cryptographically signed Receipt that binds:
- the event payload
- the policy bundle that gated it
- the policy verdict (allow/deny/escalate)
- the previous Receipt (per-tenant chain)

Receipts roll up into evidence packs (JSON-LD + PROV-O) signed with a single root_hash, exportable to regulators. A Gemini-Pro narrative on top makes the pack human-readable while preserving cryptographic verifiability via three independent anchors (pack_root_hash, prompt_hash, content_hash).

## API surface

- `GET /healthz` -- liveness probe
- `POST /v1/events` -- ingest agent event (202 Accepted)
- `GET /v1/receipts?tenant_id=X&limit=N&offset=N` -- paginated list
- `GET /v1/receipts/{receipt_id}` -- detail + live integrity check
- `GET /v1/evidence-packs?tenant_id=X&scope_start=...&scope_end=...` -- JSON-LD evidence pack
- `POST /v1/narratives?tenant_id=X&scope_start=...&scope_end=...` -- regulator-ready narrative with 3-anchor chain

## Console surface

- `/` -- HealthBadge (4-state) + ReceiptList (sortable table with click-to-detail navigation)
- `/receipts/[id]` -- Full ReceiptDetail with integrity badge (green VERIFIED / red TAMPER DETECTED)
